# Portfolio (React + Vite, deployed to GitHub Pages)

When the user finishes a project in their Projects folder, add it here by following
[ADDING_PROJECTS.md](ADDING_PROJECTS.md): screenshots as WebP in `public/projects/<id>/`,
an entry in `PROJECTS_DATA` in `src/data/portfolioData.ts` (with `images` and `docs`),
then `npm run lint` and `npm run build`. Let the user push; a push to `main` deploys the site.
